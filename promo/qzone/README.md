以上是当前本机的安装和封装状态，不是全新克隆仓库默认安装的数量。公开清单 Top-50 的 50 条定义涉及 42 个不同软件包；不能与本机 69 包混用。计数快照及所计节点 ID 记录在 `tool-counts.json`，不包含机器私有路径或凭据。

## LLM 自动适配

工作站可提取工具帮助文本，调用已配置的 LLM 接口生成输入、输出、参数和 shell 定义，再执行结构检查及合成输入试运行。定义需要审查后使用。模型接口与依赖环境需另行配置，不保证所有索引工具都能自动适配；试运行成功不替代真实数据验证。

## 可直接发布的配文

**OpenBioWorkstation：面向 Agent 协作的生物信息学工作站**

近期开发并开源了 OpenBioWorkstation，尝试将 Agent 协作纳入可视化、可检查的生物信息学分析流程。研究者确定研究问题、分析方法和参数；Agent 通过 MCP 检索工具、构建节点图、发起任务并检查输出；工作站使用 Snakemake 执行流程，并关联保存图结构、运行日志与结果文件，为协作过程提供可核查的执行记录。

截至 2026 年 11 月 1 日，当前本机已为 69 个软件包建立封装，连同内置 wrapper 与本机节点，共包含 93 个节点定义，其中 62 个带有审核标记。工具审核工作正在逐步推进。工具目录另提供 15,524 条可检索索引，并支持通过 LLM 根据命令行帮助文本生成节点定义，再进行检查、试运行与审核。软件包、节点与索引采用不同统计口径；可检索或已生成定义不等于通过真实数据验证。

项目目前面向 Linux 单机环境，提供 Agent 协作教程与研究案例。希望这一实现能够为研究者与 Agent 共同组织计算分析提供可供检验和改进的工具，欢迎同行试用、讨论与参与开发。

项目地址：https://github.com/ArchitektSpeer/openbioworkstation
