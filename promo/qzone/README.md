- **69 个软件包、78 个封装节点**：按本机注册表中的 `auto:` 定义统计；不同子命令分别计为节点，同一软件包仅计一次。
- **93 个节点定义**：78 个封装节点、5 个内置 wrapper 定义、10 个本机节点。不同接入方式可能对应相同软件，不应写为 93 款独立软件。
- **62 个带审核标记的节点**：按注册表的 `reviewed` 状态计数，不等同于独立的全面科学有效性验证。工具审核工作正在逐步推进。

以上是当前本机的安装和封装状态，不是全新克隆仓库默认安装的数量。公开清单 Top-50 的 50 条定义涉及 42 个不同软件包；不能与本机 69 包混用。计数快照及所计节点 ID 记录在 `tool-counts.json`，不包含机器私有路径或凭据。

## LLM 自动适配

工作站可提取工具帮助文本，调用已配置的 LLM 接口生成输入、输出、参数和 shell 定义，再执行结构检查及合成输入试运行。定义需要审查后使用。模型接口与依赖环境需另行配置，不保证所有索引工具都能自动适配；试运行成功不替代真实数据验证。

## 可直接发布的配文

OpenBioWorkstation 是面向 Linux 本地环境的生物信息学可视化工作流平台，集成节点图编辑、Snakemake 执行与 MCP 接口，支持研究者与 Agent 协作构建和检查计算分析流程。

截至 2026 年 11 月 1 日，当前本机已为 69 个软件包建立 78 个封装节点；连同内置 wrapper 和本机节点，共提供 93 个节点定义，其中 62 个带有审核标记。工具审核工作正在逐步推进。工具目录包含 15,524 条可检索索引，并支持基于命令行帮助文本，通过 LLM 自动生成节点定义，随后进行检查、试运行和审核。

上述软件包、节点和索引采用不同统计口径；可检索不等于可直接执行，生成定义也不等于完成真实数据验证。项目现提供中英双语文档、Agent 协作教程及研究案例材料。

项目地址：https://github.com/ArchitektSpeer/openbioworkstation
