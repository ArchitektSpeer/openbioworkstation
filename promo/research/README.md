## 解释边界 / Interpretation

WSMV 案例报告在 73 个受检位点中无位点达到 FDR < 0.10。该结果不证明不存在效应或统计等效。两项研究的统计结论、参考文献和新颖性声明均应结合原报告的方法与限制审阅，不得以软件运行成功替代科学审查。稿件采用的期刊式版面不代表期刊接收、发表或机构背书。

The WSMV case reports that none of 73 tested sites reached FDR < 0.10. This does not establish absence of an effect or equivalence. Statistical conclusions, references and novelty claims in both studies require review alongside their original methods and limitations. Successful software execution is not scientific validation. Journal-style formatting does not imply journal acceptance, publication or institutional endorsement.

本次发布包含这些 PDF、展示图和使用教程，未包含完整原始测序数据、分析脚本、参考文件或运行工作区。因此附件是研究展示材料，不能单独作为完整可复现的数据与代码归档。PDF 内历史本地路径及脚本引用可能无法在公开仓库解析。

This release includes these PDFs, presentation images and tutorials, but not complete raw sequencing data, analysis scripts, reference files or run workspaces. The attachments are a research showcase rather than a complete reproducibility archive. Historical local paths and script references inside the PDFs may not resolve in the public repository.
