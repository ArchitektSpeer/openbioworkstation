# 离线演示

在项目根目录运行 `./run-demo.sh`，或：

```bash
.venv/bin/python -m examples.demo
```

默认工作区为项目内的 `demo_workspace/`，演示启动器会注册三种本地工具。因此请通过演示入口打开该工作区，而不是普通 `ui.workstation_window` 入口。

画布预置六个节点：

- 双端 FASTQ 输入：R1、R2 各 12 条、每条 80 bp。
- FASTA 输入：一条 1000 bp 参考序列。
- 两个文件检查节点：调用 C 扩展支撑的共享检查接口，输出 JSON。
- 汇总报告节点：合并检查结果，输出 HTML 和 JSON。
- 输出节点：汇总两份报告路径。

这是用于展示 UI 和任务流的合成样本，不执行测序质控算法、比对或变异分析。

## 演示操作

1. 选择左侧输入节点，查看右侧文件预览与统计。
2. 在工具库搜索 `demo`，可看到三种本地工具；清空搜索恢复分类。
3. 在画布空白处右键，选择“全量运行”。底部显示真实 Snakemake 日志，节点颜色随状态变化。
4. 再次“全量运行”，观察缓存命中，已有结果无需重跑。
5. 在“03 · 汇总演示报告”节点右键，选择单步运行，观察只重跑报告。
6. 右键输出节点选择预览，查看报告路径；可在浏览器打开生成的 HTML。
7. 保存画布，关闭后重新运行演示启动器，布局与连线仍会保留。

`demo_workspace/results/` 为结果，`runs/` 为每次运行快照和日志。演示检查流程和报告生成均离线执行，不需要 Conda 或网络。首次启动只在工作区没有会话时创建样本；`./run-demo.sh --reset` 可重置演示画布和样本。

该演示用于本地操作与执行验证；运行产生的工作区和历史验证报告不随公开仓库发布。
